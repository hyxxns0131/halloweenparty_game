# 🎃 AX Pumpkin Studio (AX 할로윈 파티 프로젝트)

> **"나만의 잭오랜턴 피규어를 조립하고, 실시간 투표로 파티 베스트 드레서를 뽑아보세요!"**  
> HTML5, CSS3, Vanilla JavaScript 기반의 반응형 웹 애플리케이션 기획 및 아키텍처 명세서입니다.

## 📌 1. 프로젝트 개요

* **프로젝트명**: AX Pumpkin Studio (AX 할로윈 파티)
* **목표 인원**: 모임 및 사내 인원 40명 내외
* **주요 목적**:
  * 3D 피규어 스타일(동글동글한 SD 캐릭터 바디)의 잭오랜턴 캐릭터를 파츠별로 조합·커스터마이징
  * 호박 두상, 얼굴 표정, 호박 색상, 패션(상의/하의/신발), 악세서리를 다채롭게 꾸미기
  * 네임플레이트(`images/name.jpg`)에 이름을 새겨 완성 이미지 다운로드

## 🎨 2. 캐릭터 디자인 및 파츠 시스템 명세

첨부된 레퍼런스(귀엽고 통통한 미니 피규어 비율)를 기반으로 다층 레이어(Layer Canvas) 방식으로 조립됩니다.

```
[Layer 구조: 뒤에서 앞으로]
1. 배경 (Background) - 할로윈 으스스한 테마
2. 캐릭터 바디 (기본 몸통 & 다리)
3. 하의 (Pants/Skirts) & 신발 (Shoes)
4. 상의 (Tops/Costumes)
5. 호박 머리 베이스 (Pumpkin Head Base) + 꼭지
6. 눈 / 코 / 입 (Carved Face Parts - 안쪽 음영 & 발광 효과)
7. 악세서리 & 소품 (Accessories - 모자, 날개, 망토, 손 소품 등)
8. 네임플레이트 (Nameplate - 'images/name.jpg' + 작성자 이름)
```

### 1) 호박 머리 형태 (Shape 4종)
* **대두형 (Big Head)**: 머리가 몸통보다 훨씬 큰 귀여운 2등신 비율
* **롱 헤드 (Tall & Slim)**: 위아래로 길쭉한 박/호박 형태
* **납작 호박 (Flat & Chubby)**: 양옆으로 퍼지고 납작 눌린 형태
* **찌그러진 호박 (Wonky / Twisted)**: 비대칭이거나 굴곡진 익살스러운 형태

### 2) 호박 본체 컬러 팔레트 (Skin Color)
* **클래식 오렌지 (Classic Pumpkin)**
* **좀비 그린 (Rotten Green)**
* **다크 고스트 퍼플 (Midnight Purple)**
* **스푸키 화이트/아이보리 (Ghost White)**
* **섀도우 블랙 (Shadow Charcoal)**
* *(선택 기능: 컬러 피커(Color Picker) 지원 시 무제한 커스텀 가능)*

### 3) 얼굴 조각 파츠 (Face Carving)
* **눈 (Eyes)**: 클래식 삼각형, 화난 반달 눈, 땡그란 동그라미, 윙크, X자 눈 등
* **코 (Nose)**: 미니 세모, 박쥐 모양, 해골 콧구멍, 역삼각형 등
* **입 (Mouth)**: 지그재그 이빨, 뱀파이어 송곳니, 멍한 O자 입, 꿰맨 자국(Stitch) 등
* **안쪽 발광 효과**: 눈/코/입 파츠 안쪽에 어두운 음영 또는 노란빛 촛불 발광(Glow) On/Off 지원

### 4) 의상 코스튬 시스템 (Fashion Items)
* **상의 (Tops)**: 
  * 프랑켄슈타인 자켓, 줄무늬 죄수복, 뱀파이어 턱시도, 드라큘라 케이프, 기본 티셔츠
* **하의 (Bottoms)**: 
  * 찢어진 청바지, 호박색 멜빵바지, 펑크 스커트, 미라 붕대 팬츠
* **신발 (Shoes)**: 
  * 통통한 스니커즈, 마녀 뾰족 구두, 부츠, 붕대 감은 발

### 5) 악세서리 & 소품 (Accessories & Props)
* **머리/얼굴**: 뾰족 마녀 모자, 미니 박쥐 머리띠, 해골 핀, 호박 꼭지 리본
* **등/날개**: 박쥐 날개, 악마 꼬리, 거미줄 망토
* **손 소품**: 미니 사탕 바구니, 마법 지팡이, 잭오랜턴 미니 램프

### 6) 자유 꾸미기 도구 (차별화 요소)
* 프리셋 외에도 참가자 개성을 살릴 수 있도록 **자유 낙서 브러시(Blood/Slime 등)** 또는 **자유 스티커 핀 기능** 제공

## ⚙️ 4. 기술 아키텍처 및 40인 투표 구현 가이드

별도의 무거운 백엔드 서버 없이 HTML, CSS, JavaScript만으로 40명 내외의 실시간 투표를 구축하는 가장 권장되는 방식입니다.

```
[클라이언트: GitHub Pages or Vercel (정적 웹 호스팅)]
           │
           ├── 캔버스 그래픽 렌더링 (HTML5 Canvas API)
           ├── 이미지 내보내기 (canvas.toDataURL)
           │
           ▼
[초경량 무료 BaaS: Firebase Firestore]
  ├── 컬렉션: `pumpkins`
  │     ├── id: 자동생성
  │     ├── author: "홍길동"
  │     ├── imageUrl: Base64 또는 이미지 링크
  │     ├── likes: 12 (정수)
  │     └── createdAt: 타임스탬프
```

1. **호스팅**: GitHub Pages 또는 Netlify/Vercel (무료, 링크 하나로 40명 즉시 접속)
2. **데이터베이스 & 투표 동기화**: **Firebase Firestore (무료 플랜)**
   * 파티 참가자가 "출품하기"를 누르면 Firestore 문서 생성
   * 다른 참가자가 "좋아요"를 누르면 `likes` 카운트가 `+1` 증가
   * `orderBy("likes", "desc")` 쿼리를 통해 자동으로 실시간 1위부터 순서대로 재정렬

## 🚀 6. 실행 및 설정

### 실행하기
* `index.html` 을 **더블클릭**하면 바로 실행됩니다. (인터넷·서버 불필요 — 이미지가 `js/assets.js` 에 내장되어 있어요)
* `index.html#studio` → 인트로 건너뛰고 스튜디오로, `index.html#gallery` → 바로 명예의 전당 (파티장 스크린 송출용)
* 작업 중인 호박은 브라우저에 자동 보관되어 새로고침해도 이어서 꾸밀 수 있습니다.

### 이미지(에셋)를 바꿨다면
`images/` 의 원본을 수정한 뒤 아래 명령으로 `js/assets.js` 를 다시 만듭니다. (Python + Pillow 필요)
```
python tools/build_assets.py
```
* `images/parts/shapes` 호박 캐릭터 5종 · `images/parts/props` 입체 소품 시트 · `images/halloween` 인트로/배경/네임플레이트 · `images/stickers` 스티커 (halloween3·4.jpg 에서 자동 추출)

### 🎲 사탕 뺏기 (야바위 · 호박 줄다리기)
명예의 전당의 **🎲 사탕 뺏기** 버튼 → 두 게임 중 하나를 고릅니다. 출품한 사람만 참여 가능 (서버는 사탕이 움직인 뒤 12초 쿨다운을 지킴)

**🥤 야바위** — `js/shell-game.js`
* 컵 10개 중 하나에 사탕을 넣는 걸 보여준 뒤 아주 빠르게 섞고, 사탕이 든 컵을 고르는 게임
* 맞히면 → 사탕을 가진 다른 참가자에게서 1개를 랜덤으로 뺏어옴 / 틀리면(또는 섞기 시작한 뒤 포기) → 내 사탕 1개가 랜덤 참가자에게 넘어감
* 한 판 끝나면 15초 쉬었다가 다시 도전

**🪢 호박 줄다리기** — `js/tug-game.js` (실시간 1:1)
* 출품작 닉네임 목록에서 🟢 접속 중인 사람에게 **[대결 신청]** → 상대 화면(어느 화면에 있든)에 수락/거절 창이 뜸 (15초 안에 응답)
* 수락하면 3·2·1 START! → 20초 동안 **스페이스바** 또는 **[당기기!]** 버튼 연타로 줄을 내 쪽(왼쪽)으로. 가만히 두면 줄이 가운데로 돌아감
* 끝까지 당기면 즉시 KO 승리, 시간이 끝나면 줄이 더 가까운 쪽 승리 (정확히 가운데면 무승부)
* 이기면 → 그 상대의 사탕 1개를 뺏어옴 / 지면(또는 대결 중 기권·연결 끊김) → 내 사탕 1개가 그 상대에게 / 무승부는 그대로
* 실시간 통신은 Supabase Realtime 의 broadcast·presence 만 사용 (테이블 추가 없음). 신청한 쪽이 줄 위치를 계산하고 사탕 이동도 한 번만 처리
* 상대가 없거나 로컬 데모 모드일 땐 **🤖 봇과 연습하기** (사탕 이동 없음)
* 서버 함수 `candy_duel` 사용 — 기존 Supabase 프로젝트라면 `supabase/schema.sql` 을 한 번 더 실행하세요

### 40명이 함께 쓰기 (Supabase — 로그인 없이 공유)
`js/supabase-config.js` 가 비어 있으면 **로컬 데모 모드**(이 브라우저에만 저장)로 동작합니다.

1. [supabase.com](https://supabase.com) → **New project** (무료 플랜, 지역: Northeast Asia (Seoul))
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 전체를 붙여넣고 **Run**
   - 테이블·보안 규칙·쓰기 함수·이미지 버킷(`pumpkins`)·실시간 설정이 한 번에 만들어집니다 (여러 번 실행해도 안전)
3. **Project Settings → API** 에서 `Project URL` 과 `anon public`(또는 `Publishable`) 키를 `js/supabase-config.js` 에 붙여넣기
   - `service_role`/`secret` 키는 절대 넣지 마세요
4. 배포(아래) → 링크 공유. 파티 직전에 `supabase/reset.sql` 로 테스트 데이터를 지우세요.

**데이터 구조**

| 테이블 | 내용 |
|---|---|
| `entries` | 출품작 (작성자·제목·이미지 경로·사탕 수) — 1인 1작품, 다시 출품하면 교체 |
| `votes` | 사탕 던지기 (1인 1표) |
| `comments` | 출품작 댓글 |
| `candy_log` | 사탕 뺏기 기록 (쿨다운 판정, 비공개) |
| Storage `pumpkins` | 출품 이미지 (jpg) |

- 로그인 대신 브라우저마다 무작위 UUID 를 만들고, DB 에는 그 **해시만** 저장 → 공개돼도 다른 사람 행세 불가
- 테이블은 누구나 **읽기만** 가능. 쓰기는 `submit_entry` · `cast_vote` · `candy_game` · `candy_duel` · `add_comment` · `delete_comment` 함수로만 (해시로 본인 확인, 사탕 이동은 트랜잭션으로 처리해 동시에 해도 음수가 되지 않음)
- 변경 사항은 Supabase Realtime 으로 모든 화면에 즉시 반영

**무료 플랜 참고**: DB 500MB · 저장소 1GB로 40명 파티엔 (작품 이미지 1장 최대 1MB × 40명 = 40MB 정도) 충분합니다. 단 **7일 동안 아무 활동이 없으면 프로젝트가 일시 정지**되니, 파티 며칠 전 대시보드에서 상태를 확인하세요 (정지됐으면 Restore 한 번).
